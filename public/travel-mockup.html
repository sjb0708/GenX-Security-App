How it works
  1. Get the confirmation email → note the flight numbers (AA 1659, etc.)
  2. Enter the traveler's name, role, confirmation code, and each flight number
  3. App hits FlightAware API and auto-fills route, times, and live status
  4. Travel board updates automatically — delays, boarding, landed
  5. Pickup alerts surface automatically when someone's final leg arrives
